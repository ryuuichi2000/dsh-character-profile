# 人物画像卡

用户指定的人物是本次任务范围；有统计表时优先关注明确标黄的姓名，不自行批量扩展名单。用户的最新要求优先。附件中的人物类型、分值、旧卡和评价都是待核材料，不能代替独立分析。每人只交付一张同尺寸 PNG，可在回复中附事实来源。

## 从资料到结论

1. 锁定人名、地区、单位、当时身份、任期和截止日。区分活动日期、报道日期。逐条标明当时岗位，合并前职与现职中可归于本人的发言和动作，以同一口径判断个人风格。预测时核对现职职责和近期证据，前职权限只归属于当时岗位。核验当期公开原文，优先政府、人大、本人署名、主办方和具名可靠报道。缺证处留空。
2. 分开建立三层。**议题**记录接触过的领域，陪同可记“接触”；**治理风格**只看本人怎样做；**分管职责**只据独立的人事或分工文件。不要从职级、学历、地点、行业关键词或象限推断权限和人格。
3. 建事件底稿。每行留事件编号、日期、身份、事项、本人动作、具体对象、出处链接、原文依据、归因、两轴各端分及理由。多个转载合并；同一项目的同一推进过程合为一条证据链，后续材料只升级该链。集体通稿、部门行动、他人讲话、单纯到场或泛泛表态不计风格分。亲自主持且有任务部署可以计分。
4. 依下文逐轴编码。先得分，再看象限。遇同分或任一轴两端相差不超过 1，必须复核最有区分力的原文、可替代解释、跨事件重复性及删去关键记录是否改变结论。能判定就给一个主类型；复核仍不能区分时，标“证据不足”，不造点，不按职务补型。记录把握程度（较高／中等／较低），分别考虑来源、归属、时间跨度、实际后续和反证。卡面不加“暂定”，也不套用早期五类型投票法。
5. 先找活动主线，再将证据转换为卡片。遵循下方写法与版式，在导出前逐项核对。分析底稿可单独留存，分数不出现在卡面。

## 从活动主线选择摘录与预测

通读全部可用材料，在底稿按“持续解决什么问题、反复采用什么办法”归并议题。对照几条可能的主线，分别看独立事件中本人实质发言或行动的频次、覆盖的任期与时间跨度、是否有试点和后续扩大。转载合并；陪同只说明接触，会议报道密集也可能源于岗位曝光。把新近的一次调研拿掉，再看结论是否仍有支撑。记录最能解释材料的一条主线及选它的理由；证据薄弱时缩小判断范围。

02 在主线上选一至两条最能说明工作方法的事实。优先让两条各有作用，如早期试点与后来改进、问题识别与后续处置。游戏企业或营商环境与主线确有交集时优先选；用日期、场合和本人动作作简短转述，推断留给“未来预测”。

预测先回答“哪一种做法可能继续深化”，再说明“下一步可能改进哪一环”。结合已有试点、本人明确的推广方向和仍待解决的问题，用一两句日常语言写出可观察的变化。已宣布的计划写在摘录里。若只有一次性表态，或转岗后无法确认议题延续，就收窄预测或省略。

## 两轴及四种固定文案

每条证据链对每个有依据的方向分别编码。0＝不能判断或不能归于本人；1＝本人提出具体办法、明确思路；2＝有本人组织实施、具体后续或持续督办的证据。同一行为不因转载累加。同一事项确实涉及相反两端时允许分别计分，并分别摘出对应动作。

- X 左为协同推动，要求能看出多方共同任务、分工、资源配合；右为直接推动，看本人部署、定标准、压责任、督执行。多人同场本身不能算协同。
- Y 下为具体事务，看具体对象、项目、堵点或诉求；上为整体机制，看普遍规则、总体布局、长期运行。
- 画图采用统一归一化净差：X＝（直接－协同）／（直接＋协同）；Y＝（机制－事务）／（机制＋事务）。在 −1 至 +1 上画点。分母为零时该轴未知，不画二维点。确切同分保持点在轴线上；若经定性复核选类，不挪动坐标。隐藏刻度、数字坐标、分值及计算说明，显示两轴端点和四象限名称。图面透明，露出类型面板底色。

使用以下说明原文，逗号后强制换行，第二行独立显示。不得按人物改写。

| 象限 | 类型 | 固定说明 |
|---|---|---|
| 右下 | 事务推进型 | 倾向于围绕具体事项明确任务，直接推动落实。 |
| 左下 | 协调解题型 | 倾向于围绕具体问题协调各方，共同推动解决。 |
| 右上 | 系统部署型 | 倾向于围绕整体目标部署任务，直接推动落实。 |
| 左上 | 机制整合型 | 倾向于围绕长期目标建立机制，促进各方协作。 |

## 游戏企业支持度

这是一个独立于治理风格的行业信号。用手柄、小标签“游戏企业支持度”和五颗星单独成行，紧邻类型说明；允许半星，资料不足时在标签后写“未知”，与标签同色、同字号、同字重。卡上不加解释，底稿记最强证据。这是对公开支持信号的编辑判断，不推测私下好感。

按可归于本人的动作定档，不按新闻数量或行业占其全部工作的比例打分。建议锚点：主动提及游戏电竞即为明显信号，可从 3 星考虑；在行业场合专门介绍或公开支持，可取 4 星；具名走访游戏企业、专题座谈并对接具体需求，可取 4.5 星；有可核验的持续推进或具体办理结果，可取 5 星。介于相邻档可取半星。仅列席、部门签约、普通科技企业走访不等于游戏企业直接对接，不叠加转载、不要求对象必须分管游戏。正反记录冲突时复核，不能判断则显示“未知”。

## 卡面编排与文案

- 使用 [版式样例](assets/layout-example.png) 与 [可改写的 HTML 样例](assets/layout-example.html)。样例只规定视觉，不是数据输入。替换所有个人信息，包括职务、编号、日期、结论、把握程度、星级、图点、雷达标签与数值、图注及来源，检查无上一个人物残留。
- 固定 1080×1440。标题“人物画像卡”；克莱因蓝 #002FA7 外框、白色主体，主体左上带小凸起；深色中文字、浅蓝类型面板。顶部姓名适中，可缩小给正文让位。左侧主类型、固定双行说明、独立支持度组件；右侧透明 XY 图。两栏对齐，不以堆字填空。右上角写“地区 / PROFILE”，**PROFILE 后面不加编号**（不要写 PROFILE 001、002 之类）；编号属于旧样例，已废弃。
- 01“履历轨迹”：时间从左向右，选 3–4 个能交代从哪里调来、岗位怎样变化的节点。不要用纵向履历线；日期只写证据支持的精度。
- 02 从上文确定的活动主线中选取一到两项。本人发言用“值得关注的公开表态”；资料只证实参加、调研、主持等活动时用“值得关注的公开活动”。保留日期、场合、事实。转述不加引号，不夹带企业视角、主观判断、因果推论或行动建议。
- “未来预测”在末尾，从跨事件的主线提炼可能的下一步，将事实、公开计划和推断区分开。明确使用“可能”等预测措辞，不写企业对策，不把游戏企业的业务等同于电竞赛事。依据不足可省。
- 页尾灵活。有足量活动且空间合适，可左下用浅蓝矩形放预测，右下放关注领域雷达图。按人物选轴，不固定领域。数值为样本中实质涉及该议题的独立活动场数，注明样本数、观察期与单位；同场同题只计一次，顺带举例不计。若把陪同算作议题接触，应另标口径，不混入本人主动关注频次。待核维度不落点、不跨缺口连线。可支持领域不足三项或空间紧时用关键词或省图。
- 页脚标注观察期、简要来源，聊天回复或底稿附可点击原文。四象限表达“怎么做”，雷达表达“关注什么”，星级表达“对游戏企业的公开支持信号”。

## 交付检查

用任意本机可用的浏览器渲染器、SVG 或排版工具导出 PNG，无须专用服务。使用 HTML 时，在目标设备选可显示简体中文的字体；按 1080×1440、像素比 1、字体加载完成后截取卡面。实际打开最终图片，检查中文无缺字、脚注无裁切、轴方向与点位正确、两个图含义清楚、类型说明恰好两行、预测简短，并能从所选摘录追溯到该人物的活动主线。专业术语优先改写成读者熟悉的具体动作。信息多时先删次要事项，不缩字硬塞。没有可用渲染工具时交付可渲染源并说明图片尚未生成。
