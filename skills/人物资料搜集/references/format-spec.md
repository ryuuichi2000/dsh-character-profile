# 文档格式规范

本规范为输出文件的唯一格式标准。所有人物必须使用完全一致的结构，便于横向对比与后续维护。

## 一、文档骨架

```markdown
# <地区/单位>重点人物资料：<姓名1> · <姓名2> · <姓名3>

整理日期：YYYY 年 M 月 D 日（本版说明：补充了什么范围的内容；主要事实的信源口径）

---

# 一、<姓名1>

## 1.1 基本信息
## 1.2 现任职务
## 1.3 职务任免
## 1.4 履历
## 1.5 公开活动与发言

---

# 二、<姓名2>
（同构）

---

# 三、<姓名3>
（同构）
```

要求：
- 人名次序按职务层级或调研优先级排列，全文一致
- 章号用中文数字（一、二、三），小节号用 `x.y`（与章号对应：第一章为 1.1—1.5）
- 章与章之间用 `---` 分隔
- 不设目录、不设横向对比表、不设研判章节（除非用户明确要求）

## 二、基本信息表

固定 12 项，顺序不可调，缺项写"未公开"：

```markdown
| 项目 | 内容 |
|---|---|
| 姓名 |  |
| 性别 |  |
| 民族 |  |
| 出生日期 | 1981 年 10 月 |
| 籍贯 | 省 + 县/市 |
| 政治面貌 | 中共党员 |
| 入党时间 | 1998 年 12 月 |
| 参加工作时间 | 2006 年 7 月 |
| 最高学历 | 研究生 |
| 学位 | 管理学博士 |
| 毕业院校 |  |
| 专业 | （本科专业另注） |
| 其他任职 | 人大代表、政协委员等 |
```

规范：
- 年月用"1981 年 10 月"，日不详不写日；已知到日则写"1981 年 10 月 15 日"
- 数字与中文之间加半角空格（"1981 年 10 月"）
- 学历与学位分列（"研究生" / "管理学博士"）
- 若同时有其他重要身份（政协委员、民主党派），列入"其他任职"并注终止时间

## 三、现任职务

```markdown
## x.2 现任职务

<职务全称，多层职务用顿号或"兼"字连接>

兼任职务：

| 职务 | 说明 |
|---|---|
|  | 兼任机构的性质、成立时间、覆盖范围等背景 |

- 分管工作：
- 是否晋升：（与上一职务比较，注明"提拔使用/平级调动/转任"）
- 是否本地晋升：（本单位/本区成长 or 跨区调入）
- 任职年限：2026.10—
```

规范：
- 分管工作只写官方明示内容（分工文件、官网介绍、公开报道的明确表述），不推断
- 未公开分管则写"官方未公开分工文件"
- "是否晋升"必须给比较基准（原职务 → 现职务）

## 四、职务任免表

```markdown
| 时间 | 事项 |
|---|---|
| 2026.10.12 | <会议名称>决定：任命…… |
```

规范：
- 时间精确到日（有文件日期时）；只知月份写"2026.10"
- 事项写清"什么会议/什么机关决定/任命或免去什么职务"
- 按时间正序
- 表后可加一行括注依据（"任免依据：……交叉核验"）

## 五、履历表

```markdown
| 时间 | 职务 |
|---|---|
| 2000.09—2004.09 | 清华大学土木工程系学生 |
| 2026.10— | 石景山区委副书记，区政府党组书记、副区长、代区长 |
```

规范：
- 起止用"YYYY.MM—YYYY.MM"，现任写"YYYY.MM—"（结尾留空）
- 时间不详的条目写"—"，但应尽量补齐（任免文件、公示、百科交叉）
- 同一时段多个职务写在同格内，用逗号分隔，兼职用"（兼）"
- 按时间正序；求学经历可保留（判断院校、专业、导师人脉时有用）
- 履历可与其后各任职阶段标题的时间区间严格对应

## 六、公开活动与发言（核心章节）

### 6.1 阶段分组

按任职阶段分组，用三级标题，阶段名含时间区间：

```markdown
### 一、<现职单位>任职期（2026.10—）
### 二、<上一单位><职务>期（2025.12—2026.10）
### 三、<更早单位>期（2021.10—2023.05）
```

规范：
- 阶段从近到远排列；阶段内条目也按时间倒序
- 阶段边界与该段履历一致
- 阶段内无记录时，标题下写"该阶段未见公开活动记录"
- 一人跨度大时可按"单位 + 职务层级"双重划段（如"海淀区委副书记期""海淀区委常委、常务副区长期"）

### 6.2 单条活动格式

```markdown
#### 2026.10.31　调研八宝山街道、金顶街街道重点工作

- 场合：<活动名称、主办方、规模>
- 点位／议程：<具体地点、环节>
- 表态内容：
  > 引语原文第一段。
  > 引语原文第二段。
- 同场：<其他出席人员的姓名与职务>
- 来源：<发布主体> <链接>
- 交叉验证：<另一独立信源> <链接>
```

规范：
- 日期与标题之间用全角空格（`　`）分隔
- 标题用动词开头、简洁描述（"调研…""出席…""带队走访…""主持…并讲话"）
- "表态内容"只放引号内原文；多段用多个 `>` 行；不改写、不拼接、不加评价
- 无引语时不要硬凑，写"会议报道未披露发言内容"
- 来源必须给可点击链接；多源时主源在前，"交叉验证"另列
- 会议类条目补"规模/数据"（参会人数、发布指标），对判断规格有用
- 纯礼节性出席（无发言、无表态）可只保留一行说明，不必展开

### 6.3 特殊条目写法

| 情形 | 写法 |
|---|---|
| 署名文章 | 标题作为条目标题，注明刊物/公众号、署名身份，摘引涉及关键工作的段落 |
| 名单类出现（如防汛指挥部） | 单列一条，注明"以某职务身份列名"，不作表态 |
| 回溯报道中的旧发言 | 标注"任职某职期间，具体日期未披露"，并列报道时间与链接 |
| 群体活动中的随行 | 写"随某某（职务）一同调研/参加"，不虚构其发言 |
| 时间跨度 | `2024.12.05—06` |

### 6.4 阶段内的排序与取舍

- 优先收录：有实质表态、涉及分管领域、涉及产业/企业/政策、规格较高（一把手在场、市级以上活动）
- 可舍弃：纯慰问性、无信息量的出席；同一活动的多篇重复报道（合并为一条，保留多源链接）
- 每人每个阶段建议 3—8 条，过少说明检索不足，过多则需按上述标准筛

## 七、语言与排版

- 全中文，专有名词保留原文（如 DEAS、MUSA）
- 数字与中文之间加空格："3 条""100 余人""2026 年"
- 书名号用于文件、报刊、方案（《…》），引号用中文引号（""），内层引号用（''）
- 不出现"待核实""疑为""可能""应该"等不确定表述；不确定则不写
- 不使用表情符号、不使用加粗强调（标题层级已足够）

## 八、文件命名

`<地区/单位>重点人物资料-<姓名1>·<姓名2>·<姓名3>-<YYYYMMDD>.md`

多人超过三人时用"-等N人"收尾。修订版追加 `-v2`、`-v3`，并在文首"整理日期"后括注本版变更范围。

## 九、交付前格式检查

- [ ] 每人五章齐全，编号连续（1.1—1.5 / 2.1—2.5 / 3.1—3.5）
- [ ] 基本信息 12 项齐全，缺项已写"未公开"
- [ ] 履历时间与活动章节的阶段区间一致
- [ ] 每条活动都有日期、场合、来源
- [ ] 所有引语都在引用块内，且为原文
- [ ] 表格列数一致、无空单元格（用"未公开"或"—"填充）
- [ ] 链接完整可访问，无断链、无乱码
