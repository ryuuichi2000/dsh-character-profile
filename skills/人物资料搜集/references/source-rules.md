# 信源规则：分级、核验与冲突处理

## 一、信源分级

| 级别 | 定义 | 示例 | 可否单独采信 |
|---|---|---|---|
| S1 一级官方 | 事项的原始发布主体官网 | 政府门户网站的政务动态/任免公告、人大常委会任免决定、政协会议报道、法院裁判文书、党委部门官网、部委官网 | 可 |
| S2 官方媒体 | 党报党刊、通讯社、政府主办新闻网站 | 人民日报及客户端、新华社、北京日报及"北京号"、央广网、中国新闻网（地方频道）、省市党报 | 关键事实需再补一源 |
| S3 机构自发布 | 协会、学会、商会、企业、园区、街道公众号与官网 | 京能集团官网、哈工大研究院公众号、街道公众号、企业公众号 | 不可单独采信，需 S1/S2 佐证 |
| S4 市场化媒体 | 财经/时政媒体、门户网站及其转载 | 新浪财经、今日头条号、搜狐、中华网 | 仅作线索与佐证 |
| S5 百科与聚合 | 百度百科、360 百科、搜狗百科、人物资料站 | — | 仅作线索，不作依据 |

判定原则：
- 同一事件的"主办方发布"优于"参与者发布"优于"旁观者转述"
- "来源：XX 单位"的转载稿，按原始单位定级（如北京号标注"来源：区委网信办"→ 实质为 S1）
- 企业公众号报道领导来访，属 S3；若同时有政府官网报道，以政府官网为主源

## 二、交叉核验规则

1. **双源规则**：职务任免、出生年月、学历学位、籍贯、分管工作、具名表态，须有 2 个独立信源，或 1 个 S1。
2. **独立性**：两个信源不能是同一篇稿件的转载（同一稿件在 5 个平台转载仍算 1 源）。判断方法：比对文字是否逐句雷同。
3. **主源选择**：信息最完整、最接近原始发布者为"主源"，写入"来源"；其余写入"交叉验证"。
4. **引语规则**：只摘引号内的原文；跨段引用用多个引用块，不做省略号拼接式改写；转述内容不得加引号。
5. **数字规则**：会议规模、金额、指标数据须与原文一致，不得换算或四舍五入。

## 三、日期核验

三种信号必须自洽：

| 信号 | 位置 | 说明 |
|---|---|---|
| 发布日 | 页面"发布时间"字段、列表页时间 | 最可靠的年份锚点 |
| URL 日期 | `t20240528_xxx`、`/2024/06/12/`、`202408/t20240820` | 常为发布日期，可反推年份 |
| 正文日期 | "6月24日""日前""近日""昨天" | 事件发生时间 |

处理规则：

1. 正文有完整"年月日"→ 直接采用，仍核对是否与发布日矛盾（发布会早于活动日 = 异常，需重新核）
2. 正文只有"月日"→ 用发布日/URL 年份补全；若发布日为次年 1—2 月，注意跨年（12 月的活动常在次年 1 月发布）
3. 正文为"近日""日前"→ 采用发布日，条目标注为"（近日）"或直接使用发布日
4. 正文为"昨天"→ 发布日减 1 天
5. 回顾/回访/周年综述类报道 → 刊发日不是活动日，须在条目中写明"报道时间"，活动时间另注或标注"具体日期未披露"
6. 时间跨度条目（"12月5日至6日""9月16—17日"）→ 用 `2024.12.05—06` 格式
7. 无法确定年份 → 不收录，或写"具体日期未披露"

## 四、冲突处理顺序

1. 一级官方 vs 其他 → 采用官方
2. 官方任免文件 vs 媒体报道 → 采用任免文件
3. 同级别、时间不同 → 采用时间更近者（人员职务会变动，旧稿常已过期）
4. 同级别、时间相同但内容矛盾 → 两说并存则整项不写入；仅表述差异则取更具体者
5. 人物同名混淆 → 用单位、职务、地域三重限定确认是同一人；不能确认则不合并

## 五、检索渠道清单（可直接套用的检索式）

```
"姓名" "单位"                        # 基础
"姓名" 调研|座谈|致辞|签约|出席        # 活动
"姓名" 任前公示|任免|任命|辞去         # 任免
"姓名" 分管|分工|负责                  # 职责
site:gov.cn "姓名" 单位
site:<地方政府域名> "姓名"
site:<人大/政协/法院域名> "姓名"
"姓名" 简历|履历|出生|籍贯|学历
"姓名" + 旧单位 + 职务                 # 回溯既往职务（关键）
"事件名" + 姓名                        # 交叉验证具体活动
```

## 六、无法核实时的写法

| 情形 | 写法 |
|---|---|
| 官方从未公开某字段 | 表格内写"未公开"，章节末加一句说明检索范围与结论 |
| 两源矛盾且无法判定 | 该字段不写入表格 |
| 活动存在但日期不明 | 条目保留，日期写"具体日期未披露"，或用"报道时间"替代并注明 |
| 某任职阶段查无记录 | 该阶段标题下写"该阶段未见公开活动记录" |
| 只有单一 S3 信源 | 不收录，除非用户明确要求"线索级信息也可" |
